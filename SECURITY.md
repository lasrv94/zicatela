# Seguridad

Si encuentras una vulnerabilidad, no abras un issue público ni incluyas datos personales, tokens o credenciales. Usa el reporte privado de GitHub Security Advisories:

https://github.com/lasrv94/zicatela/security/advisories/new

Incluye pasos para reproducir, impacto esperado y una propuesta de mitigación cuando sea posible. La respuesta y el plazo de corrección se gestionarán según la gravedad reportada.
